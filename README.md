# Wallapop → Telegram: детский велосипед (Дения)

Бот раз в 20 минут проверяет Wallapop и присылает в Telegram **новые**
объявления о велосипедах с колесом 26–29″ по цене 50–200 € в радиусе 60 км
от Дении.

Работает **бесплатно** на GitHub Actions — сервер и карта не нужны.
Устройство то же, что у бота для ss.lv: крон → проверка → отправка,
отправленные объявления запоминаются в `state.json`, повторов не будет.

---

## Запуск (5 минут)

Если бот для ss.lv уже настроен, **токен можно взять тот же** — просто
пропусти шаг 1 и используй существующие значения секретов.

### 1. Создать Telegram-бота

В Telegram найди **@BotFather** → `/newbot` → придумай имя и username
(должен заканчиваться на `bot`). BotFather пришлёт **токен** вида
`123456789:AAExxxxx` — это секрет, в код его вставлять не надо.

Свой `chat_id`: напиши боту **@userinfobot**, он ответит числом `Id:`.

### 2. Залить папку на GitHub

**New repository** → имя любое (например `bike-telegram-bot`) → **Public**
(для публичных репозиториев Actions бесплатны без лимита) → **Add file →
Upload files** → перетащи все файлы, включая скрытую папку `.github`.

### 3. Добавить секреты

**Settings → Secrets and variables → Actions → New repository secret**:

| Name | Значение |
|------|----------|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID`   | твой chat_id (несколько — через запятую) |

### 4. Включить

Вкладка **Actions** → «I understand my workflows, enable them» →
слева **bike watcher** → **Run workflow**.

> **Первый запуск ничего не присылает.** Он только запоминает все текущие
> объявления — иначе прилетело бы больше сотни сообщений разом. Дальше
> приходят только новые.

## Настройка под себя

Всё, что обычно хочется поменять, лежит вверху `bot.py` в блоке «Что ищем»:

```python
HOME_LAT = 38.8408     # Дения. Свои координаты: Google Maps → правый клик
HOME_LON = 0.1057      # по точке → первая строка это «широта, долгота»
RADIUS_KM = 60

MIN_PRICE_EUR = 50     # дешевле — обычно хлам или запчасти
MAX_PRICE_EUR = 200

MIN_WHEEL_IN = 26      # размер колеса в дюймах
MAX_WHEEL_IN = 29      # пропускает 26 / 27,5 / 28 / 29
```

**Поисковые фразы** — в `searches.txt`, по одной на строку, `#` в начале
отключает строку. Фразы должны быть **на испанском** — объявления пишут
по-испански.

**Как часто проверять** — в `.github/workflows/bike-watch.yml` строка
`cron: "*/20 * * * *"`.

**Сбросить память** (прислать всё заново) — удали `state.json` из репозитория.

### Проверить настройки локально, ничего не отправляя

```bash
python3 bot.py --dry-run
```

Покажет, что нашлось и что отсеялось, но в Telegram не напишет и
`state.json` не тронет. Удобно после правки фильтров.

## Как это устроено

У Wallapop нет RSS, как у ss.lv, но есть внутренний JSON API, который
работает без ключей и авторизации:

```
GET https://api.wallapop.com/api/v3/search
    ?keywords=...&latitude=...&longitude=...
    &source=search_box&order_by=closest
```

Важные детали, найденные опытным путём:

- **`source=search_box` обязателен.** Без него API отвечает `400`.
- **`order_by=closest` — единственный режим, который учитывает координаты.**
  При `newest` возвращается общеиспанская лента, где ближайшее объявление
  может быть за 1900 км.
- **Параметр `distance` игнорируется.** Радиус приходится считать самому по
  координатам каждого объявления — этим занимается `distance_km()`.
- **Пагинация — через JWT-токен** в `meta.next_page`, по 40 объявлений на
  страницу. Так как сортировка по близости, обход прекращается, как только
  страница целиком ушла за радиус.

Размер колеса берётся из заголовка, включая дробные («27,5 pulgadas» → 27.5).
Если размер определить не удалось, объявление **всё равно присылается** —
лучше лишнее сообщение, чем упущенный велосипед.

Фильтр аксессуаров смотрит на **первые два слова заголовка**: испанские
объявления почти всегда начинаются с названия предмета, поэтому
«Sillín de bicicleta Rockrider» отсеивается как седло, а «Bicicleta niño
con ruedas» проходит, хотя в нём тоже есть слово из стоп-листа.

## Известные риски

- **API неофициальный.** Wallapop может в любой момент поменять параметры —
  тогда в логе Actions появятся ошибки запросов. Чинится правкой параметров.
- **CloudFront.** Wallapop стоит за CloudFront, который иногда режет трафик
  с дата-центровых IP. С домашнего IP всё работает; если с GitHub Actions
  начнёт прилетать `403`, бота можно перенести на домашний Mac (крон +
  `launchd`) — код менять не придётся.

## Facebook Marketplace

Пока не подключён — сознательно. FB отдаёт `400` ещё до страницы логина:
нужен полноценный браузер (Playwright) с живой залогиненной сессией и
домашним IP, а значит бесплатные GitHub Actions отпадают. Варианты, если
Wallapop окажется мало: гонять Playwright на домашнем маке (бесплатно, но
мак должен быть включён, и лучше завести для этого отдельный FB-аккаунт)
либо платный готовый скрапер вроде Apify (~30–50 € в месяц).
